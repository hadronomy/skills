# Pages: one quadrant per page

Label each page by its quadrant before writing a word. The quadrants split
by reader mode:

| Page | Reader | Shape |
|---|---|---|
| Tutorial | learning | Single path, no branches, visible result per step |
| How-to guide | task at work | Goal-first steps, branches allowed, no background |
| Reference | lookup at work | Dry facts mirroring the machinery, complete, no steps |
| Explanation | understanding at study | Discursive context, background, trade-offs, no steps |

Conflating modes produces bad docs for every mode. Split mixed pages along
the quadrant lines. Link across types instead of embedding: how-tos link to
reference for option lists, tutorials link out to explanation for theory.

Tutorials carry one visible outcome per step and never branch. How-tos
assume competence and stay scoped to the goal. Reference stays austere and
complete within scope. Explanation answers why and tolerates perspective.

Review pass per page: quadrant labeled, shape matches the table, no leaked
mode, links resolve, examples run.
