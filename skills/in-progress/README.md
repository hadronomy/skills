## Model-invoked

- **agent-progress** — live progress for a long-running command, rendered in the
  macOS menu bar and the Claude Code status line, at zero context cost. The
  menu-bar renderer is macOS-only.
- **windows-mcp** — driving the Windows desktop on `workstation` through the
  windows MCP server. Machine-specific: it names a private host and assumes the
  SSH stdio bridge is up.
